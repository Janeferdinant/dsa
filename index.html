Sparse Polynomial Addition using Arrays

▼
Problem Statement: Represent two polynomials with sparse non-zero terms using arrays of structures (coefficient, exponent) and compute their sum by merging corresponding terms in descending order of powers.

Structured Algorithm Steps:

  1. Define structure Term with fields coeff and exp.
  2. Initialize read pointers i = 0 for Poly A, j = 0 for Poly B, and k = 0 for Result.
  3. While i < nA and j < nB:
  4. a. If A[i].exp == B[j].exp: Set Res[k].coeff = A[i].coeff + B[j].coeff, Res[k].exp = A[i].exp, and increment i, j, k.
  5. b. If A[i].exp > B[j].exp: Set Res[k] = A[i], increment i and k.
  6. c. If A[i].exp < B[j].exp: Set Res[k] = B[j], increment j and k.
  7. Copy any remaining elements of Poly A to Res.
  8. Copy any remaining elements of Poly B to Res.
  9. Output the resultant polynomial and terminate.
Vector SVG Flowchart Logic:
C Source Program (PCCSL307 Compliant) 
#include <stdio.h>

struct Term {
    int coeff;
    int exp;
};

int addPolynomials(struct Term A[], int nA, struct Term B[], int nB, struct Term Res[]) {
    int i = 0, j = 0, k = 0;
    while (i < nA && j < nB) {
        if (A[i].exp == B[j].exp) {
            int sum = A[i].coeff + B[j].coeff;
            if (sum != 0) {
                Res[k].coeff = sum;
                Res[k].exp = A[i].exp;
                k++;
            }
            i++; j++;
        } else if (A[i].exp > B[j].exp) {
            Res[k++] = A[i++];
        } else {
            Res[k++] = B[j++];
        }
    }
    while (i < nA) Res[k++] = A[i++];
    while (j < nB) Res[k++] = B[j++];
    return k;
}

int main() {
    struct Term A[] = {{4, 3}, {3, 2}, {5, 0}};
    struct Term B[] = {{2, 3}, {4, 1}, {1, 0}};
    struct Term Res[10];
    int nRes = addPolynomials(A, 3, B, 3, Res);

    printf("Resultant Polynomial: ");
    for (int i = 0; i < nRes; i++) {
        printf("%dx^%d%s", Res[i].coeff, Res[i].exp, (i < nRes - 1) ? " + " : "\n");
    }
    return 0;
}

Sparse Matrix Transpose & Addition

▼
Problem Statement: Given matrices with predominantly zero values, represent them in 3-Tuple (Row, Column, Value) coordinate format. Implement matrix addition and the fast transpose algorithm in O(cols + nonzeros) time.

Structured Algorithm Steps:

  1. Represent matrix as array of triplets where tuple[0] stores (rows, cols, total_non_zeros).
  2. For addition: Traverse tuple A and B in row-major order. If (rA == rB && cA == cB), add values. Else append the element with smaller linear index.
  3. For Fast Transpose:
  4. a. Count frequency of elements in each column of matrix A.
  5. b. Compute starting address array for each column in transposed matrix B.
  6. c. For each non-zero element in A, place it at its exact target index in B with swapped row and column indices.
  7. Terminate and display transposed 3-tuple structure.
Vector SVG Flowchart Logic:
C Source Program (PCCSL307 Compliant) 
#include <stdio.h>

struct Element {
    int row, col, val;
};

void fastTranspose(struct Element a[], struct Element b[]) {
    int totalTerms = a[0].val;
    int cols = a[0].col;
    int rowTerms[50] = {0}, startPos[50] = {0};

    b[0].row = a[0].col;
    b[0].col = a[0].row;
    b[0].val = totalTerms;

    if (totalTerms <= 0) return;

    for (int i = 1; i <= totalTerms; i++) rowTerms[a[i].col]++;
    startPos[0] = 1;
    for (int i = 1; i < cols; i++) startPos[i] = startPos[i - 1] + rowTerms[i - 1];

    for (int i = 1; i <= totalTerms; i++) {
        int j = startPos[a[i].col]++;
        b[j].row = a[i].col;
        b[j].col = a[i].row;
        b[j].val = a[i].val;
    }
}

int main() {
    struct Element A[10] = {{4, 4, 3}, {0, 1, 10}, {1, 3, 20}, {3, 0, 30}};
    struct Element B[10];
    fastTranspose(A, B);

    printf("Row\tCol\tVal\n");
    for (int i = 0; i <= B[0].val; i++) {
        printf("%d\t%d\t%d\n", B[i].row, B[i].col, B[i].val);
    }
    return 0;
}

Infix to Postfix Conversion & Stack Evaluation

▼
Problem Statement: Convert an arithmetic expression from infix notation to postfix (Reverse Polish Notation) using an operator stack and evaluate the resulting postfix expression using an operand stack.

Structured Algorithm Steps:

  1. Initialize an operator stack for conversion.
  2. Scan infix expression from left to right:
  3. a. If operand, output directly to postfix string.
  4. b. If '(', push to operator stack.
  5. c. If ')', pop from stack to output until '(' is encountered.
  6. d. If operator op, pop operators with >= precedence from stack to output, then push op.
  7. Pop all remaining operators to output string.
  8. For Evaluation: Scan postfix string. If operand, push to stack. If operator, pop op2, pop op1, compute op1 (operator) op2, push result back.
  9. Top of stack is final numerical evaluation.
Vector SVG Flowchart Logic:
C Source Program (PCCSL307 Compliant) 
#include <stdio.h>
#include <ctype.h>
#include <string.h>

char stack[100];
int top = -1;

void push(char c) { stack[++top] = c; }
char pop() { return stack[top--]; }
int prec(char c) {
    if (c == '^') return 3;
    if (c == '*' || c == '/') return 2;
    if (c == '+' || c == '-') return 1;
    return 0;
}

void infixToPostfix(char infix[], char postfix[]) {
    int k = 0;
    for (int i = 0; infix[i]; i++) {
        char ch = infix[i];
        if (isalnum(ch)) postfix[k++] = ch;
        else if (ch == '(') push(ch);
        else if (ch == ')') {
            while (top != -1 && stack[top] != '(') postfix[k++] = pop();
            pop();
        } else {
            while (top != -1 && prec(stack[top]) >= prec(ch)) postfix[k++] = pop();
            push(ch);
        }
    }
    while (top != -1) postfix[k++] = pop();
    postfix[k] = '\0';
}

int main() {
    char infix[] = "((A+B)*C)-D";
    char postfix[100];
    infixToPostfix(infix, postfix);
    printf("Infix Expression   : %s\n", infix);
    printf("Postfix Expression : %s\n", postfix);
    return 0;
}

Queue, DEQUEUE, and Circular Queue using Arrays

▼
Problem Statement: Implement linear queue, Double-Ended Queue (DEQUEUE), and Circular Queue using fixed-size arrays with wrap-around modulo arithmetic for efficient memory reuse.

Structured Algorithm Steps:

  1. Circular Queue: Maintain front and rear index pointers initialized to -1.
  2. Enqueue(item): If (front == 0 && rear == MAX-1) || (front == rear + 1), Queue is FULL. Else rear = (rear + 1) % MAX; arr[rear] = item.
  3. Dequeue(): If front == -1, Queue is EMPTY. Item = arr[front]. If front == rear, reset front = rear = -1. Else front = (front + 1) % MAX.
  4. Deque Operations: Support insertFront (front = (front - 1 + MAX) % MAX) and deleteRear (rear = (rear - 1 + MAX) % MAX).
  5. Display elements from front to rear taking wrap-around into account.
Vector SVG Flowchart Logic:
C Source Program (PCCSL307 Compliant) 
#include <stdio.h>
#define SIZE 5

int cqueue[SIZE];
int front = -1, rear = -1;

int isFull() { return (front == (rear + 1) % SIZE); }
int isEmpty() { return (front == -1); }

void enqueue(int val) {
    if (isFull()) { printf("Queue Overflow!\n"); return; }
    if (front == -1) front = 0;
    rear = (rear + 1) % SIZE;
    cqueue[rear] = val;
    printf("Enqueued: %d (rear=%d)\n", val, rear);
}

int dequeue() {
    if (isEmpty()) { printf("Queue Underflow!\n"); return -1; }
    int val = cqueue[front];
    if (front == rear) front = rear = -1;
    else front = (front + 1) % SIZE;
    return val;
}

int main() {
    enqueue(10); enqueue(20); enqueue(30); enqueue(40);
    printf("Dequeued: %d\n", dequeue());
    enqueue(50); enqueue(60); // Wraps around circularly!
    return 0;
}

Browser Navigation using Doubly Linked List

▼
Problem Statement: Simulate web browser back and forward button functionality using a Doubly Linked List, where new visits prune forward history and pointers move bidirectionally.

Structured Algorithm Steps:

  1. Define structure Node with char url[100], and pointers *prev and *next.
  2. Initialize current pointer pointing to home page node.
  3. Visit(new_url):
  4. a. If current->next != NULL, delete/prune all forward nodes to prevent stale history branches.
  5. b. Allocate new Node, copy new_url, set new->prev = current, new->next = NULL.
  6. c. Link current->next = new and update current = new.
  7. Back(): If current->prev != NULL, update current = current->prev. Display current->url.
  8. Forward(): If current->next != NULL, update current = current->next. Display current->url.
Vector SVG Flowchart Logic:
C Source Program (PCCSL307 Compliant) 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct PageNode {
    char url[100];
    struct PageNode *prev, *next;
};

struct PageNode *current = NULL;

void visit(const char *url) {
    struct PageNode *newNode = (struct PageNode*)malloc(sizeof(struct PageNode));
    strcpy(newNode->url, url);
    newNode->next = NULL;
    newNode->prev = current;
    if (current != NULL) current->next = newNode;
    current = newNode;
    printf("Visited -> %s\n", current->url);
}

void back() {
    if (current && current->prev) {
        current = current->prev;
        printf("Back to <- %s\n", current->url);
    } else printf("Back disabled (start of history)\n");
}

void forward() {
    if (current && current->next) {
        current = current->next;
        printf("Forward to -> %s\n", current->url);
    } else printf("Forward disabled (latest page)\n");
}

int main() {
    visit("google.com");
    visit("github.com");
    visit("stackoverflow.com");
    back();
    back();
    forward();
    visit("ktu.edu.in"); // Forward history pruned!
    forward(); // Disabled!
    return 0;
}

Polynomial Addition & Multiplication using Singly Linked Lists

▼
Problem Statement: Implement dynamic addition and multiplication of two arbitrarily sized polynomials using singly linked lists with nodes ordered in descending powers.

Structured Algorithm Steps:

  1. Define struct PolyNode with int coeff, int exp, and pointer struct PolyNode *next.
  2. Polynomial Addition: Traverse both linked lists. While both exist, compare exponents. If equal, sum coefficients and append if non-zero. Otherwise append node with higher exponent. Append remaining nodes.
  3. Polynomial Multiplication:
  4. a. Initialize result list as empty.
  5. b. For each term p1 in Poly A, traverse each term p2 in Poly B.
  6. c. Multiply coefficients (p1->coeff * p2->coeff) and add exponents (p1->exp + p2->exp).
  7. d. Insert product term into result list in sorted order, combining like terms.
  8. Display the resulting polynomial.
Vector SVG Flowchart Logic:
C Source Program (PCCSL307 Compliant) 
#include <stdio.h>
#include <stdlib.h>

struct PolyNode {
    int coeff, exp;
    struct PolyNode *next;
};

struct PolyNode* insert(struct PolyNode *head, int c, int e) {
    struct PolyNode *newNode = (struct PolyNode*)malloc(sizeof(struct PolyNode));
    newNode->coeff = c; newNode->exp = e; newNode->next = NULL;
    if (!head || e > head->exp) { newNode->next = head; return newNode; }
    struct PolyNode *curr = head;
    while (curr->next && curr->next->exp >= e) curr = curr->next;
    if (curr->exp == e) { curr->coeff += c; free(newNode); return head; }
    newNode->next = curr->next;
    curr->next = newNode;
    return head;
}

struct PolyNode* multiply(struct PolyNode *h1, struct PolyNode *h2) {
    struct PolyNode *res = NULL;
    for (struct PolyNode *p1 = h1; p1; p1 = p1->next) {
        for (struct PolyNode *p2 = h2; p2; p2 = p2->next) {
            res = insert(res, p1->coeff * p2->coeff, p1->exp + p2->exp);
        }
    }
    return res;
}

int main() {
    struct PolyNode *P1 = NULL, *P2 = NULL;
    P1 = insert(P1, 3, 2); P1 = insert(P1, 5, 0); // 3x^2 + 5
    P2 = insert(P2, 2, 1); P2 = insert(P2, 4, 0); // 2x + 4
    struct PolyNode *Prod = multiply(P1, P2);
    printf("Product Polynomial: ");
    for (struct PolyNode *p = Prod; p; p = p->next) printf("%dx^%d ", p->coeff, p->exp);
    printf("\n");
    return 0;
}

Arithmetic Expression Tree & Traversal

▼
Problem Statement: Construct an expression tree from an arithmetic postfix expression and generate its prefix, infix, and postfix equivalents via recursive tree traversals.

Structured Algorithm Steps:

  1. Define struct TreeNode with char data, and pointers *left, *right.
  2. Initialize a stack of TreeNode pointers.
  3. Scan postfix string token by token:
  4. a. If operand, create node, set left=right=NULL, and push node pointer to stack.
  5. b. If operator, create node, pop right child from stack, pop left child from stack, attach children, and push operator node back to stack.
  6. Root of expression tree is the single node remaining on stack top.
  7. Perform Inorder (Infix), Preorder (Prefix), and Postorder (Postfix) traversals recursively.
Vector SVG Flowchart Logic:
C Source Program (PCCSL307 Compliant) 
#include <stdio.h>
#include <stdlib.h>
#include <ctype.h>

struct TreeNode {
    char data;
    struct TreeNode *left, *right;
};

struct TreeNode* stack[50];
int top = -1;

void push(struct TreeNode *n) { stack[++top] = n; }
struct TreeNode* pop() { return stack[top--]; }

struct TreeNode* buildTree(char postfix[]) {
    for (int i = 0; postfix[i]; i++) {
        struct TreeNode *node = (struct TreeNode*)malloc(sizeof(struct TreeNode));
        node->data = postfix[i];
        if (isalnum(postfix[i])) {
            node->left = node->right = NULL;
        } else {
            node->right = pop();
            node->left = pop();
        }
        push(node);
    }
    return pop();
}

void inorder(struct TreeNode *r) {
    if (!r) return;
    if (r->left) printf("(");
    inorder(r->left);
    printf("%c", r->data);
    inorder(r->right);
    if (r->right) printf(")");
}

int main() {
    char postfix[] = "ab+c*";
    struct TreeNode *root = buildTree(postfix);
    printf("Inorder (Infix) : "); inorder(root); printf("\n");
    return 0;
}

Word-Meaning Dictionary using Binary Search Tree

▼
Problem Statement: Implement a dictionary of word-meaning pairs using a Binary Search Tree (BST) supporting logarithmic lookup, dynamic word insertion, and alphabetical in-order traversal.

Structured Algorithm Steps:

  1. Define BSTNode with char word[50], char meaning[150], and pointers *left, *right.
  2. Insert(root, word, meaning):
  3. a. If root is NULL, allocate new node and return it.
  4. b. Compare word with root->word using strcmp.
  5. c. If strcmp < 0, root->left = Insert(root->left, word, meaning).
  6. d. Else if strcmp > 0, root->right = Insert(root->right, word, meaning).
  7. Search(root, key): If root is NULL or strcmp == 0, return root. Else recurse left or right based on comparison.
  8. Inorder(root): Recurse left, print word & meaning, recurse right (alphabetical order).
Vector SVG Flowchart Logic:
C Source Program (PCCSL307 Compliant) 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct BSTNode {
    char word[50];
    char meaning[150];
    struct BSTNode *left, *right;
};

struct BSTNode* insert(struct BSTNode *root, const char *w, const char *m) {
    if (!root) {
        struct BSTNode *n = (struct BSTNode*)malloc(sizeof(struct BSTNode));
        strcpy(n->word, w); strcpy(n->meaning, m);
        n->left = n->right = NULL;
        return n;
    }
    int cmp = strcmp(w, root->word);
    if (cmp < 0) root->left = insert(root->left, w, m);
    else if (cmp > 0) root->right = insert(root->right, w, m);
    return root;
}

struct BSTNode* search(struct BSTNode *root, const char *w) {
    if (!root || strcmp(w, root->word) == 0) return root;
    if (strcmp(w, root->word) < 0) return search(root->left, w);
    return search(root->right, w);
}

int main() {
    struct BSTNode *root = NULL;
    root = insert(root, "Queue", "FIFO data structure");
    root = insert(root, "Array", "Contiguous memory blocks");
    root = insert(root, "Tree", "Hierarchical non-linear structure");

    struct BSTNode *res = search(root, "Queue");
    if (res) printf("Found: %s => %s\n", res->word, res->meaning);
    return 0;
}

Expt 9 CO1, CO3 • Level K4

Landmine Maze Shortest Distance

▼
Problem Statement: In an NxM grid containing obstacle walls ('X') and landmines ('M'), determine the shortest safe distance of every open cell from any landmine using multi-source Breadth-First Search (BFS).

Structured Algorithm Steps:

  1. Initialize distance grid dist[R][C] with -1 for all cells.
  2. Initialize a queue of coordinate pairs (r, c).
  3. Locate all landmines ('M'): set dist[r][c] = 0 and enqueue all landmine cells simultaneously (Multi-Source BFS).
  4. While queue is not empty:
  5. a. Dequeue current cell (r, c).
  6. b. For each of the 4 neighbors (r+1,c), (r-1,c), (r,c+1), (r,c-1):
  7. c. If neighbor is within grid bounds, is not a wall ('X'), and dist is currently -1:
  8. Set dist[nr][nc] = dist[r][c] + 1 and enqueue (nr, nc).
  9. Display the distance matrix where each cell displays its minimum safe clearance.
Vector SVG Flowchart Logic:
C Source Program (PCCSL307 Compliant) 
#include <stdio.h>

#define R 4
#define C 4

struct Cell { int r, c; };

int dist[R][C];
struct Cell queue[50];
int front = 0, rear = 0;

int main() {
    char grid[R][C] = {
        {'O', 'O', 'O', 'M'},
        {'O', 'X', 'O', 'O'},
        {'M', 'O', 'O', 'O'},
        {'O', 'O', 'X', 'O'}
    };

    for (int i = 0; i < R; i++) {
        for (int j = 0; j < C; j++) {
            if (grid[i][j] == 'M') { dist[i][j] = 0; queue[rear++] = (struct Cell){i, j}; }
            else dist[i][j] = -1;
        }
    }

    int dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
    while (front < rear) {
        struct Cell curr = queue[front++];
        for (int d = 0; d < 4; d++) {
            int nr = curr.r + dr[d], nc = curr.c + dc[d];
            if (nr >= 0 && nr < R && nc >= 0 && nc < C && grid[nr][nc] != 'X' && dist[nr][nc] == -1) {
                dist[nr][nc] = dist[curr.r][curr.c] + 1;
                queue[rear++] = (struct Cell){nr, nc};
            }
        }

Q20: What is memory fragmentation in dynamic allocators? CO4 · K4
Internal fragmentation occurs when allocated space exceeds requested space. External fragmentation occurs when free memory is broken into chunks too small to satisfy requests.

Coalescing is the process of merging adjacent free memory blocks into a single contiguous block when memory is freed to minimize external fragmentation.

O(N log K), where N is the total number of elements across all lists and K is the number of lists.

A full binary tree has nodes with either 0 or 2 children. A complete binary tree is completely filled on all levels except possibly the last, filled from left to right.

Pop op2 first, pop op1 second, evaluate (op1 operator op2), and push the result back onto the operand stack.

Load factor lambda = n / m, where n is number of elements and m is table size. Keeping lambda < 0.75 ensures average O(1) performance.

First-Fit allocates the first free block that is large enough (fastest). Best-Fit searches for the smallest free block that fits (minimizes wasted block space).
